### ✨ Visão Geral do Projeto

Inspirado nas gigantes do streaming como a Netflix, este projeto recria a experiência de uma tela de cinema diretamente no seu navegador. Com uma interface minimalista e focada, ele convida o usuário a mergulhar na imersão de um filme.

---

### 💻 Tecnologias Utilizadas

Este projeto foi construído com as seguintes ferramentas, garantindo um código limpo e de fácil manutenção:

* **HTML:** A espinha dorsal da página, fornecendo a estrutura semântica para o conteúdo.
* **Sass (SCSS):** Para uma estilização elegante e organizada, transformando CSS em um processo mais inteligente e eficiente.

---

### 🚀 Como Rodar o Projeto

#### Pré-requisitos

Apenas um navegador web moderno como Chrome, Firefox ou Safari.

#### Instalação

1.  Clone este repositório para a sua máquina local usando o terminal:
    ```bash
    git clone [https://github.com/lucasr4m0n/Cinema-VNW.git](https://github.com/lucasr4m0n/Cinema-VNW.git)
    ```
2.  Navegue até o diretório do projeto:
    ```bash
    cd Cinema-VNW
    ```

#### Execução

Como este é um projeto puramente estático, basta **abrir o arquivo `index.html`** no seu navegador de sua preferência.
